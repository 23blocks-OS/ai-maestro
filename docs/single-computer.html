Start · One computer

Install, then open the dashboard

Same installer as the home page. aimaestro.sh/install is scripts/remote-install.sh, byte for byte. Read it before you run it.

curl -fsSL aimaestro.sh/install | bash

If Copy cannot use the clipboard, select the command and copy it.

  1. Run it on macOS, Linux, or Ubuntu on WSL2. You need git and curl. It installs Node.js 24 when Node is missing or older than 22, plus Yarn, pm2, tmux, and jq.
  2. Open http://localhost:23000. That is the default port. --port or AIMAESTRO_PORT changes it.
  3. Create one session and start the coding tool you installed. The rest of this page, including how it works, is that workflow.

How It Works

Three simple steps to AI agent orchestration

1

Install AI Maestro

curl -fsSL aimaestro.sh/install | bash

One command installs everything.

2

Create Agent Sessions

Click "Create Session" in the dashboard. Name it with your project structure: 

myapp-frontend-ui
myapp-backend-api
myapp-tests-integration
3

Start Your Agents

Click any session to open the terminal. Run your favorite AI tool: 

claude
# or
codex
# or
cursor

When to Upgrade?

Single computer mode works great for most developers. Consider upgrading when you need:

→ Multiple Computers

More than 10-15 agents, or need to distribute workload across machines

→ Docker Containers

Environment isolation, dependency conflicts, or reproducible builds
