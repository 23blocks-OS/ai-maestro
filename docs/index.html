Install AI Maestro.

A dashboard and orchestrator for AI coding agents (Claude Code, Codex, Grok Build, and others) on one computer or many. This site is how you install it, run it, and extend it. What it is for a company, and why, is on getaimaestro.com.

curl -fsSL aimaestro.sh/install | bash

If Copy cannot use the clipboard, select the command and copy it.

aimaestro.sh/install is scripts/remote-install.sh from this repository, byte for byte. Read it before you run it. The raw GitHub address of that file is the same script.

Before you run it

  • The installer is bash. It runs on macOS, Linux, and Windows inside WSL2. It does not install on native Windows. On Windows, install WSL2 first (wsl --install in PowerShell), open Ubuntu, and run the command there. WSL2 guide.
  • You need git and curl. On macOS without git, the installer tells you to run xcode-select --install. On Linux it names your package manager.
  • It installs what is missing: Node.js 24 when Node is absent or older than 22, plus Yarn, pm2, tmux, and jq. On macOS it can install Homebrew first. On Linux it uses apt, dnf, pacman, zypper, or apk when one of those is present, and it asks for build tools (make, a C++ compiler, python3) so the terminal module can compile.
  • It asks which coding assistant to install (Claude Code, Codex, both, or skip) unless you pass -y. Tailscale is optional and defaults to no. It is for reaching agents on other machines, not for a single computer.
  • Building needs about 2.5 GB of RAM plus swap. On Linux the installer stops below that and prints how to add swap, or to use a machine with 4 GB. A Mac with less is warned and not stopped. Once built, the server itself is a few hundred megabytes. Linux sizing.

For a script, with the prompts accepted:

curl -fsSL aimaestro.sh/install | bash -s -- -y

Open the dashboard

The installer serves the dashboard at http://localhost:23000. --port or AIMAESTRO_PORT changes that. The software in this repository is the MIT-licensed program you run yourself. This site does not create an account.

A coding agent still talks to its own provider when you use Claude Code, Codex, Grok Build, or another hosted model. The dashboard being on your machine is not the same thing as the model running there.

The first useful workflow is one agent on one computer: install, open the dashboard, create a session, start the tool you installed. That page is one computer.

On your phone

AI Maestro for iPhone is a separate App Store app. It connects to a host you already run: see who needs you, approve, chat. Scan the QR code from Settings > Hosts. Learn more. The price is the one on the App Store page.
