AI Maestro: install and docs

A dashboard and orchestrator for AI coding agents (Claude Code, Codex, Grok Build and others) on one computer or many. What it is and why: getaimaestro.com.

INSTALL

curl -fsSL aimaestro.sh | bash

This runs scripts/remote-install.sh from the GitHub repository; read it first if you like. The dashboard opens at http://localhost:23000. On Windows, see the WSL2 guide.
